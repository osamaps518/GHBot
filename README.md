# GHBot

An Arabic-first fitness app, starting with personal targets and onboarding.

The current backend foundation provides FastAPI, local PostgreSQL, migrations,
and automated checks. Follow the [backend setup guide](backend/README.md) to run
the API and tests. Sign-in, profiles, and target calculations are later issues.
